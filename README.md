# 그리기 연구실 01 · 기분 편

> 같은 얼굴, 다른 마음 — 얼굴이 안 보여도 읽히는 몸의 기분, 喜怒哀楽+驚虚 여섯 감정, 공 위에 그리는 눈, 기분을 더하는 빛과 그림자를 실험으로 익히고, AI 표정 문장·가림 영역·VFX 표정 값으로 옮겨 봅니다.

**사이트:** https://adminmrobo.github.io/drawing_lab_01/
**앞 시리즈:** [구조 먼저 보는 캐릭터 그리기 연구실](https://adminmrobo.github.io/adminmrobo-structure_first_drawing_lab/) · [구조 먼저 그리기 연구실 01 · 옷장 편](https://adminmrobo.github.io/structure_first_drawing_lab_01/)

## 등장인물
| 역할 | 캐릭터 |
|---|---|
| 모델 | 조수 하루(1·4부), 인턴2 모아(2부), 인턴1 시아(3부), 5부는 셋 모두 |
| 손님 모델 | 박사(2부 분노, 4부 빛 둘) |
| 화가 | 주판봇(얼굴부터·결과부터 서두름), 초파리 연구원(몸과 원리부터 의심) |
| 평가단 | X1·X2·X3 (닮음·원리·자연스러움) |
| 해설 | 박사 |

모델은 모두 20대 성인 연구원입니다(박사는 성인 남성). 원리 실습은 연구실 의상으로 합니다.

## 구성
| 부 | 페이지 | 다루는 것 |
|---|---|---|
| 목차 | `index.html` | 세 줄 요약, 읽는 순서와 시간, 편 목록, 전체 흐름, 등장인물, 원리와 출처 |
| 1부 | `01_body_mood.html` | 실루엣으로 읽히는 기분, 머리·목·어깨 세 선, 목의 범위(몸 + 목), 걸음(보폭 = 키 × (0.35 + 0.15 × 기분)) |
| 2부 | `02_six_emotions.html` | 눈썹·입 두 축, 분노의 두 단계, 놀람의 흰자(1 − r²), 밝은 멍함과 어두운 멍함 |
| 3부 | `03_eyes.html` | 각도별 눈 폭(cos), 공 위의 눈동자, 눈꺼풀 단계와 감은 눈 곡선, 기분별 눈 |
| 4부 | `04_light_mood.html` | 빛의 방향(세기 × cos), 빛 둘의 명·중·암, 역광·테두리 빛·반사판, 기분 터치 |
| 5부 | `05_ai_vfx.html` | 표정 문장 여섯 조각, 얼굴만 가려 다시 그리기(넓이 비율), 표정 값 섞기(가중합), 화풍별 과장 배수 |
| 6부 | `06_failure_lab.html` | 진단 순서 + 표정 그림 실패 8종 + 표정 낱말이 나이를 바꾸는 현상 |
| 7부 | `practice/index.html` | 실전 연습장: 무대·표정 공방·조명실·진단 데스크 |

1~6부 끝에는 **프롬프트로 직접 만들어 보기**가 있습니다. 이 페이지 그림을 만드는 프롬프트(A)와 원리를 빼거나 바꾼 비교 문장(B), 결과 확인표, 참고 그림(`assets/refs/`) 내려받기를 담았습니다.

모든 실험은 외부 라이브러리 없이 동작하며, 그림 파일이 없어도 페이지가 완성 상태입니다.

## 그림
- 그림 33장(표지 8 + 본문 17 + 실패 8)은 Genspark로 만듭니다. 요청문: `docs/image_requests/` (저장 이름은 `checklist.csv`).
- 비교 그림(B 결과) 12장 요청문: `docs/image_requests_make/` — 꾸러미 1을 받은 뒤 진행합니다.
- 본문용 33장과 비교용 11장을 반영했습니다(2026-11-23). 5부 얼굴 다시 그리기의 B 결과는 6부 f8 그림으로 대신 보여 줍니다.
- 그림은 원본 해상도 그대로 넣습니다(표지 1920×1080 무손실 WebP). 픽셀아트 표지를 줄이면 픽셀이 뭉개집니다.
- 그림을 바꿀 때는 `assets/img/{이름}.webp`로 넣고 `python3 build/build.py`, 표지는 `python3 build/make_og.py`까지 다시 돌립니다.
- 표지는 16비트 RPG풍 픽셀아트, 본문은 애니풍(5부 4단계만 네 화풍). 실사풍은 캐릭터를 코스프레한 가상의 성인 모델입니다.

## 원리와 출처
1~4부의 원리는 林晃(Go office)·九分くりん 『キャラの気持ちの描き方 — 表情・感情の表と裏を描き分けよう』 p.11~70을 참고했습니다. 책의 그림·문장·도식·구성 순서는 옮기지 않았고, 연구실 캐릭터와 직접 움직이는 실험으로 새로 구성했습니다. 교복·맨몸 습작 예시는 쓰지 않았습니다. 수식·기법 출처(램버트 코사인 법칙, 블렌드셰이프, RePaint 2022, 잠재 확산 모델 2022 등)는 각 페이지 바닥글에 있습니다.

## 빌드와 점검
```
python3 build/build.py           # 페이지 + panels.js
python3 build/check_numbers.py   # 본문 숫자 검산
python3 build/make_og.py         # 공유 미리보기
python3 build/check_pages.py     # 390px·1280px 가로 넘침·콘솔 오류·깨진 실험 (로컬 서버 8765)
python3 build/check_missions.py  # 연습장 미션 판정 (로컬 서버 8765)
python3 build/make_requests.py && python3 build/make_requests_make.py   # 그림 요청문
```
